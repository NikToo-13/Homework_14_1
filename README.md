# О описания основных сущностей и инициализации объектов.


## Создан класс Product

Имеет следующие свойства:
1) название (name - str)
2) описание (description - str)
3) цена (price - float)
4) количество в наличии (quantity - int).

## Создан класс Category

Имеет следующие свойства:
1) название (name - str)
2) описание (description - str)
3) список товаров категории (products - list)

* реализован подсчет котегорий через атрибут: category_count и подсчет продуктов через атрибут: product_count
